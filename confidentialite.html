Politique de confidentialité

Dernière mise à jour : 2 juillet 2026

Données collectées

Lors de votre utilisation du site, nous pouvons collecter :

  • Nom
  • Adresse email
  • Numéro de téléphone (dont numéro Mobile Money pour le paiement)
  • Informations liées aux commandes
  • Données techniques de navigation

Le paiement est traité par notre prestataire de paiement Mobile Money (OpenPay), qui reçoit les informations strictement nécessaires à la transaction. Nous ne stockons jamais de code secret ou d'identifiant Mobile Money.

Utilisation des données

Les données sont utilisées uniquement pour :

  • Traiter les commandes
  • Assurer le support client
  • Améliorer nos services
  • Prévenir les fraudes

Protection des données

Nous mettons en œuvre des mesures techniques et organisationnelles afin de protéger vos informations personnelles.

Cookies

Le site peut utiliser des cookies afin :

  • d'améliorer votre expérience utilisateur ;
  • d'analyser le trafic ;
  • de mémoriser certaines préférences.

Vous pouvez modifier vos préférences de cookies via les paramètres de votre navigateur.

Conservation

Les données personnelles sont conservées uniquement pendant la durée nécessaire aux finalités pour lesquelles elles ont été collectées ou conformément aux obligations légales applicables.

Vos droits

Vous pouvez demander :

  • l'accès à vos données ;
  • leur rectification ;
  • leur suppression lorsque cela est applicable ;
  • des informations sur leur traitement.

Toute demande peut être adressée à : contact@apay-digital-cg.store
